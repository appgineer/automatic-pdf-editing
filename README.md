# PDF 자동화 시스템

A컴퓨터에서 공유폴더로 PDF + config.json을 보내면, B컴퓨터에서 자동 처리하는 시스템.

## 입출력 폴더 구조

```
입력폴더(GUI에서 선택)/
  김민수/
    쉽게쓴파이썬/
      Image_001.pdf, Image_002.pdf, config.json

출력폴더(GUI에서 선택)/
  김민수 님.zip    ← 고객의 모든 책 완료 시 자동 압축
```

### config.json

```json
{
  "type": "고급",
  "black_point": 30,
  "white_point": 220,
  "ocr_language": "Korean",
  "split_after_ocr": false,
  "split_by_pages": "1-20,21-50",
  "split_by_size": 200,
  "crop_mm": {"top": 2, "bottom": 2, "left": 2, "right": 2}
}
```

## 처리 파이프라인 (책 1권 단위)

책 폴더 안의 PDF는 **각각 따로** 아래 1~5를 거친 뒤, 마지막에 하나로 병합된다.

1. **레벨 조정** - config type="고급"일 때만 적용
2. **300페이지 분할** → `_s` 접미사
3. **ABBYY OCR** (pyautogui GUI 자동화) → `_OCR` 접미사
4. **조각 합치기**
5. **이미지 재압축** - 고급일 때만 (JPEG2000→JPEG, 아이패드 렉 방지)
6. **PDF 합치기** - PDF가 여러 개면 파일명 숫자 오름차순으로 병합
7. **여백 자르기** - `crop_mm` 값이 있을 때만. 모든 페이지의 CropBox를 줄여 여백을 가린다
8. **최종 분할** (선택, config에 따라)
9. **ZIP 압축** - 고객의 모든 책 완료 → `고객이름 님.zip` 생성

### 여백 자르기

Acrobat의 페이지 자르기와 같은 **가리기** 방식이다. 보이는 영역(CropBox)만 줄이므로
이미지 데이터는 파일에 남고 용량도 줄지 않지만, 이미지를 다시 만들지 않아 빠르고
화질이 그대로다. 여백 값은 `pdf-level-preview`에서 눈으로 보고 정한 위/아래/좌/우(mm)다.
ABBYY 뒤에 두어, ABBYY가 CropBox를 어떻게 다루는지에 좌우되지 않게 했다.

### PDF 여러 개 넣기

파일명의 숫자를 오름차순으로 이어 붙인다 (`Image_001` → `Image_002` → ...).
번호는 순서만 정하며 연속일 필요는 없다 — `Image_005`, `Image_008`이면 005의
마지막 장 다음에 008의 첫 장이 붙는다.

### 페이지 누락 검증

ABBYY는 완료 판정이 "저장 파일 크기가 안 변하면 끝"이라 페이지가 빠진 채로
저장돼도 통과할 수 있다. 그래서 조각마다 처리 전후 페이지 수를 비교하고,
불일치하면 그 조각만 다시 처리한다(총 2회). 그래도 안 맞으면 **작업을 오류로
마감하고 출력 파일을 만들지 않는다** — 페이지가 빠진 결과물이 ZIP으로 나가는
것을 막기 위해서다. 오류난 책은 다음 실행 때 자동으로 재처리된다.

## 프로젝트 구조

```
automatic-pdf-editing/
├── run_automation.py           # 진입점
├── settings.json               # 입출력 폴더 경로 (자동 생성)
├── automation/
│   ├── app.py                  # 앱 통합
│   ├── config.py               # 설정 저장/불러오기
│   ├── models.py               # Job, BookConfig, JobStatus
│   ├── watcher.py              # 폴더 감시 (5초 폴링)
│   ├── queue_manager.py        # 작업 큐
│   ├── pipeline/
│   │   ├── runner.py           # 파이프라인 실행
│   │   ├── merge.py            # PDF 합치기
│   │   ├── split.py            # PDF 분할
│   │   ├── page_utils.py       # 첫 페이지 복사/삭제
│   │   ├── ocr.py              # ABBYY OCR 자동화
│   │   ├── abbyy_editor.py     # ABBYY 레벨 조정 자동화
│   │   ├── crop.py             # 여백 자르기 (CropBox 줄이기)
│   │   └── compress.py         # ZIP 압축
│   └── gui/
│       ├── main_window.py      # 메인 윈도우
│       ├── job_tree.py         # 작업 목록 트리
│       └── controls.py         # 버튼/폴더선택
```

## GUI 화면

```
┌──────────────────────────────────────────┐
│ 입력폴더: [C:\input    ] [찾기]           │
│ 출력폴더: [C:\output   ] [찾기]           │
│                          [시작]  [중지]   │
├──────────────────────────────────────────┤
│ ▼ 김민수                                  │
│   ● 쉽게쓴 파이썬    작업중               │
│   ○ 영어교과서       대기중               │
│ ▼ 박지영                                  │
│   ○ 수학의정석       대기중               │
│                      [▲위로] [▼아래로]    │
├──────────────────────────────────────────┤
│ 현재: 쉽게쓴 파이썬 - OCR 처리중          │
└──────────────────────────────────────────┘
```

- 상태: ●작업중(초록) ○대기중(회색) ●완료(파랑)
- 순서 변경: 대기중인 항목 클릭 후 위로/아래로
- 새 폴더 감지 시 자동 추가

## 핵심 설계

### 스레드 구조 (3개)
- **메인**: tkinter GUI
- **감시**: 폴더 폴링 (5초 간격)
- **작업**: 파이프라인 순차 실행

### 파일 안정성 감지
- PDF 크기를 폴링 간격(5초)마다 비교, 변화 없으면 전송 완료로 판단

### 설정 저장
- `settings.json`에 입력/출력 폴더 경로 저장
- 프로그램 재시작 시 자동 불러오기
